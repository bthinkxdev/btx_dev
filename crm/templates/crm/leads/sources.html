How to connect a form

POST the form fields (JSON or form-encoded) to the source's inbound URL. Authenticate with either header:

  • X-Signature: hex HMAC-SHA256 of the raw body using the source secret (recommended)
  • X-Source-Secret: the source secret, for server-side posts

Every payload is stored raw first (inbound inbox), then deduplicated and assigned. Send an id field to make retries safe.

The secret is shown on each source's edit page to users with the configure permission.
